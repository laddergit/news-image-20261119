A program that draws the world news of Thursday 19 November 2026 into one 1024×1024 image: GTA VI launches at midnight on PS5 and Xbox, Anthropic's record $81.3B IPO debuts on the Nasdaq, the world court finds Myanmar guilty of genocide against the Rohingya, Trump, Xi and Putin hold a three-way summit in Shenzhen, and Iran widens its Gulf attacks. Pure Node.js standard library — the image is generated pixel by pixel from a fixed layout and a 5×7 bitmap font, deterministically, with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
